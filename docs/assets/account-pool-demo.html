自动换号规则

开启「启用账号池」即生效：失败时依次用池内其他可用账号重试

1 每一次请求都由池子的排序选出服务账号（可用优先，其次积分高、快过期的积分包、凭据更新的）， 所以上面那行「当前使用」是排序的结果，不一定是你手动选的那个。该账号失败时， 再按同一个排序取下一个可用成员重试，直到有人接手或全部不可用；全部失败才把错误报出来（并注明尝试过几个账号）。
2 只跳过「已知不可用」的成员：仍在冷却期内的限流账号、凭据被上游拒绝的账号。 从没测试过的账号默认视为可用——刚发现的登录不该因为「还没测」就被排除在外。 积分也参与排序，但只在有新鲜读数时（卡片轮询 / 批量测试 / 保存时读到的），请求路径不会为了排序去打上游。
3 限流、无积分、凭据失效、网关/网络错误都会换号——这些都是某个账号的状态，换一个很可能就过了。 请求本身不合法（HTTP 400）不换：同一个请求体换谁都一样是 400，重试只是白等。
4 不写回你保存的选择。排序只通过运行时覆盖决定「谁服务」，从不改写你选定的账号； 关掉账号池，你选定的那个立刻完全恢复生效。上面那行「当前使用」就是当下真正在服务的账号。

账号池设置

● 有未保存的修改

下面是偏好设置：改动后需要点「保存」才落盘（与「模型管理」一致）。 池里的探测结果由插件自动写入，不经过这个保存按钮， 因此保存不会把你刚测出来的结果回退掉。

启用账号池 开启后，请求在上游失败时会依次用池里其他可用账号重试，直到有人接住或全部不可用为止。 你自己的账号永远排第一，下一个请求仍从它开始。关闭时跟随你选择的账号，失败就如实报错。
目标测试模型 自动（默认）：从本区域模型目录里挑一个倍率为 0 的免费模型， 多个候选取上下文窗口最大的。国内版与国际版挑出的模型可能不同—— 国际版目前有 3 个免费模型，国内版要等模型目录刷新后才出现。 也可以手动指定，手动指定的值优先于自动挑选。
修改任一设置后即可保存。
