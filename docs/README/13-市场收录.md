## 市场收录与展示
插件已包含可安装的 `dsh.bundle` manifest，并发布到 npm。社区市场通常从 [Awesome DSH Plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) 注册表同步条目；
仓库内的条目镜像位于 [`awesome-dsh-plugin-submission/dingminhua__dsh-connect-workbuddy.yml`](../../awesome-dsh-plugin-submission/dingminhua__dsh-connect-workbuddy.yml)。
**条目已于 PR [#3812](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/pull/3812) 合并收录（2026-08-30）**。
> ⚠️ **条目合并之后不会自己更新。** #3812 收录时插件还在 2.0.15，注册表上挂的描述因此一直停在当时的能力：没提国内版/国际版双供应商、没提每次刷新读取积分倍率、没提账号池自动换号，也没说明签到是**手动**的（签到会真实领取奖励，只在用户点按钮时执行）。**插件每次有大的能力变化，条目也要另开一次 PR 跟上**——注册表评审明确「描述必须属实、会对着代码核」。当前那条更新是 PR [#10281](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/pull/10281)。
**收录目录规范**（依据 [contributing.md](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/blob/main/contributing.md)）：
  - 每个插件一个 YAML：`data/plugins/<owner>__<repo>.yml`，字段为 `url`（与仓库地址完全一致）、`name`（`owner/repo`）、`category`（有效值之一，
  本项目为 `model`）、`description.en`（必填，以句号结尾）/ `description.zh`（可选）；描述中含 `: ` 必须加引号。
  - 仓库必须声明 `dsh.bundle` manifest（本项目 `dsh.bundle.patch: ./cordis.patch.yml`），且被 `dsh-plugin` topic 标记；
  **只声明 `dsh.client` 是最常见的被拒原因**。仓库创建满 1 天由 CI 自动检查（**没有提交数门槛**，那条已废除）。
  - 两个 README（`README.md` / `README.zh.md`）由脚本生成，不得手工编辑；修改 YAML 后执行 `node scripts/generate-readme.mjs` 重新生成。
  - 一个 PR 最多收录 3 条；只改自己的条目，不动其他插件。
市场卡片中的截图与 GitHub README 徽章是两套机制：
  - **GitHub 徽章**由本 README 顶部的 Shields/dshfind 图片链接生成。
  - **市场截图**按当前约定由**插件自己仓库根目录的 `screenshots.json`** 声明（本项目声明了 [screenshots.json](../../screenshots.json)，
  含使用界面截图），注册表 `data/screenshots.json` 是旧约定下的回退，**不再添加新键**（本项目已在提交前撤销该文件的改动）。
  - **市场图标**在注册表条目里用可选的 `icon:` 字段声明（本项目指向 `icons/dsh-connect-workbuddy-128.png`）：**必须是 GitHub 托管的位图**（png/jpg/jpeg/webp），
  SVG 与第三方图床会被拒；不写则回退到作者头像。它并不是 npm `package.json` 的通用字段，也不是 README 徽章。
**插件卡上那句标题与简介不是本插件渲染的**——那是 DSH 插件管理器读的**包元数据**：它按 `locale/<lang>.json` 的 `meta.title` / `meta.description` 取词（`locale/en.json` 是锚点，
缺了它 `zh.json` 永远不会被读；`exports` 里缺 `"./locale/*.json"` 通配则整个目录被**静默**跳过），英文回退到 `package.json` 的 `description`。
因此同一句话在本仓库写在三处，并由 [`tests/locale-meta.spec.ts`](../../tests/locale-meta.spec.ts) 钉死：卡面字典（`locale/en.json` / `locale/zh.json`）、
英文回退（`package.json.description`）、市场条目草稿（`awesome-dsh-plugin-submission/dingminhua__dsh-connect-workbuddy.yml` 的 `description.en` / `description.zh`）。
**改一处就要同改三处。**
