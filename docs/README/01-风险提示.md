## 风险提示

> **WorkBuddy 已开始限制非官方客户端请求。本项目不保证相关接口长期可用，上游一旦收紧限制，插件可能失效。请先阅读文末[「免责声明」](17-免责声明.md#免责声明)，自行评估账号风险。使用官方 WorkBuddy 客户端始终是最安全的选择。**

这个插件只做一件事：**省掉在 WorkBuddy 客户端和 DSH 之间来回切换的麻烦**。你已经在自己的机器上登录了 WorkBuddy，插件只是把那份已有的登录态接到 DSH 的模型选择器上，
让你在写代码的地方直接用到它——不提供账号、不共享凭据、不绕过计费。每一次调用都消耗**你自己账号**的额度，按上游给出的倍率真实扣费，插件从不修改账号状态，也不附带任何提权或刷额度的能力。

它依赖的是 WorkBuddy 客户端自身的接口（非官方开放 API），所以上游调整时插件可能需要跟着调整——这是这类工具的常态，也是这条提示存在的原因。**请自行评估账号风险后再决定是否安装。**
